# Example Ladder

The example ladder explains how Mortartium should teach the field.

A reader should not encounter a strange claim first. A reader should encounter the taxonomy first, then see increasingly specific examples move through the layers.

## Purpose

The ladder prevents two failures:

1. Jumping from motif to claim.
2. Drowning the reader in artifact cards without explaining the field.

Every example should climb the same ladder:

1. Field question.
2. Layer path.
3. Media class.
4. Form class.
5. Archetype.
6. Concrete example.
7. Evidence type.
8. Claim boundary.
9. Open test.

## Ladder levels

### Level 0 — Field question

Start with the big research question.

Example: how do cultures transform death, remains, ruin, and destructive material processes into art, architecture, ritual authority, and transmissible memory?

### Level 1 — Layer path

Place the example across the layers:

- Rite.
- Substrate.
- Process.
- Medium.
- Form.
- Symbolic operation.
- Institution / authority.
- Reception / restoration.
- Evidence / claim boundary.

### Level 2 — Media class

Identify the material field:

- Human bodily media.
- Animal bodily media.
- Plant media.
- Mineral and earth media.
- Civilizational remains and ruins.

### Level 3 — Form class

Identify the artifact or architectural form:

- Burial / containment.
- Vertical / axial.
- Threshold / passage.
- Light / image.
- Text / inscription.
- Wall / road / built surface.
- Sound / mask / body extension.
- Ruin / restoration.

### Level 4 — Archetype

Name the recurring interpretive pattern:

- Death-Bind.
- Weeping Wall.
- Light-Body.
- Relic-Core.
- Inscribed Skin.
- Bone-to-Color.
- Royal Furnace.
- Threshold / Initiation.
- Ruin-as-Body.
- Sounding Remains.
- Column-Tomb.

### Level 5 — Concrete example

Only now introduce a specific object, object class, or motif.

Examples:

- Lime mortar joint.
- Parchment manuscript.
- Roman cippus.
- Trajan's Column.
- Capitol Crypt.
- Rose window.
- Bone chapel.
- Brick horror motif.

### Level 6 — Evidence type

State what kind of source can support the example:

- Conservation analysis.
- Archaeological report.
- Museum catalog.
- Primary recipe.
- Ritual manual.
- Institutional history.
- Esoteric/literary text.
- Remembered-source prompt.

### Level 7 — Claim boundary

State what the example does not prove.

### Level 8 — Open test

State what evidence would move the example forward.

## Worked ladder: lime mortar joint

### Field question

How does broken or transformed matter become architectural body?

### Layer path

- Rite: construction, repair, restoration.
- Substrate: limestone, sand, water, possible ash or crushed brick.
- Process: calcination, slaking, mixing, carbonation.
- Medium: lime mortar.
- Form: joint between brick or stone.
- Symbolic operation: death-bind, repairable joint, sacrificial medium.
- Institution: mason, builder, conservator.
- Reception: decay, repointing, restoration ethics.
- Evidence: conservation guides, mortar analysis, petrography.

### Media class

Mineral and earth media.

### Form class

Wall / road / built surface.

### Archetype

Death-Bind; Weeping Wall.

### Concrete example

Historic lime mortar joint.

### Claim boundary

Mortar as death-bind is symbolic interpretation. It is not strict etymology and not proof of Masonic or esoteric intent.

### Open test

Add source-backed artifact card with lime mortar chemistry and restoration guidance.

## Worked ladder: parchment manuscript

### Field question

How does animal body become text, law, memory, or sacred transmission?

### Layer path

- Rite: religious, legal, scholarly, monastic, administrative transmission.
- Substrate: animal skin.
- Process: liming, scraping, stretching, drying, polishing, inscription.
- Medium: parchment or vellum.
- Form: manuscript, codex, scroll, charter.
- Symbolic operation: inscribed skin.
- Institution: scribe, monastery, court, church, archive.
- Reception: conservation, cataloging, digitization.
- Evidence: codicology, manuscript conservation, craft history.

### Media class

Animal bodily media.

### Form class

Text / inscription.

### Archetype

Inscribed Skin.

### Concrete example

Parchment manuscript.

### Claim boundary

Animal parchment is ordinary. It does not imply human skin or hidden ritual unless object-specific evidence supports that claim.

### Open test

Add sourced manuscript material card.

## Worked ladder: Column-Tomb lane

### Field question

How does vertical architecture translate death, ash, office, victory, or memory into public order?

### Layer path

- Rite: burial, cremation, triumph, memorialization, civic dedication.
- Substrate: ash, urn, stone, inscription, column, base.
- Process: cremation, quarrying, carving, inscription, relocation.
- Medium: column, cippus, funerary altar, sarcophagus, crypt support.
- Form: vertical memorial.
- Symbolic operation: grave-as-axis, ascent, civic apotheosis.
- Institution: family, senate, emperor, state, museum, heritage authority.
- Reception: ruin survival, relocation, national memory, esoteric rereading.
- Evidence: archaeology, inscriptions, site records, institutional histories.

### Media class

Human bodily media; mineral and earth media; civilizational remains.

### Form class

Vertical / axial; burial / containment; ruin / restoration.

### Archetype

Column-Tomb.

### Concrete examples

Trajan's Column; Roman cippi; Capitol Crypt; National Capitol Columns.

### Claim boundary

Column symbolism or tomb association does not prove a full body inside a column shaft.

### Open test

Find object-specific sources for ash deposits, cippus cavities, body-proportioned forms, and later reception.

## Worked ladder: Horror of bricks lane

### Field question

How does fired earth become a carrier of horror, labor memory, sacrifice, or blood-earth symbolism?

### Layer path

- Rite: currently unknown; possible construction, labor, kiln, sacrifice, or literary horror context.
- Substrate: clay, sand, iron, lime, water, kiln atmosphere.
- Process: digging, mixing, molding, drying, firing.
- Medium: brick.
- Form: wall, road, kiln, factory, prison, temple, grave structure.
- Symbolic operation: royal furnace, blood-earth, fired body, forced transformation.
- Institution: brickmaker, mason, state, patron, industrial system, literary author.
- Reception: Lovecraftian/architectural horror, labor memory, legend, material science.
- Evidence: literary source, material brick chemistry, labor history, folklore, kiln archaeology.

### Media class

Mineral and earth media.

### Form class

Wall / road / built surface.

### Archetype

Royal Furnace; Death-Bind; Ruin-as-Body.

### Concrete examples

Lovecraft brick-horror motif; red/yellow brick color chemistry; forced-labor brickmaking; kiln sacrifice traditions if sourced.

### Claim boundary

Red brick does not imply blood. Lovecraft supports literary reception, not material recipe.

### Open test

Pin exact Lovecraft image/source when provided; add brick color chemistry sources; investigate labor and ritual lanes separately.

## Rule for future examples

Do not create a new artifact card until the example can be placed on this ladder.

If it cannot climb the ladder yet, it remains a motif.
