# Evidence Matrix

The evidence matrix is the operational center of Mortartium. It turns layered interpretation into a repeatable research method.

Each artifact, site, object class, or material process should be entered as a row or artifact card with the fields below.

## Matrix fields

| Field | Purpose |
|---|---|
| Object / site | Name of the artifact, site, object class, or process. |
| Archetype(s) | One or more Mortartium archetypes. Overlap is expected. |
| Material substrate | Physical matter involved. |
| Destructive process | Burning, slaking, firing, grinding, dissolving, scraping, cutting, stretching, binding, etc. |
| Binding / fixation | How the transformed matter is stabilized. |
| Visible artifact | What the viewer encounters. |
| Hidden layer | Chemistry, substrate, relic presence, repair, contamination, symbolic code, or institutional claim. |
| Symbolic operation | Death-bind, purification, resurrection, illumination, inscription, containment, threshold, confession, reconciliation, etc. |
| Institutional authority | Mason, priest, guild, conservator, scribe, alchemist, patron, museum, archive, state, lineage. |
| Evidence available | Conservation report, lab analysis, source text, field photo, artifact study, archive, recipe, ritual text. |
| Claim grade | Established, strongly supported, plausible, speculative, open test, rejected. |
| Open tests | Evidence needed to upgrade, downgrade, or reject the reading. |
| Source links | Internal source cards or citations. |

## Use rules

1. Do not mark a symbolic reading as material evidence.
2. Do not infer human remains from the presence of calcium, phosphate, lime, or ash without object-specific support.
3. Do not infer intentional esoteric doctrine from craft process alone.
4. Do allow layered readings where the evidence supports multiple planes.
5. Convert hard claims into open tests.
6. Document rejected or downgraded claims rather than deleting them.
