## Reading

Trajan's Column is a key Column-Tomb test object because it fuses vertical imperial memory, carved narrative, state authority, and a reported ash-base tradition. The artifact should not be flattened into “body inside column.” The more careful reading is layered:

- **Public layer:** imperial victory monument and narrative relief.
- **Architectural layer:** freestanding column, pedestal, internal stair, vertical monumentality.
- **Funerary layer under test:** reported deposition of Trajan's and Plotina's ashes in the base.
- **Symbolic layer:** victory, ascent, public memory, imperial body translated into stone.

## Claim boundary

Mortartium does not claim that Trajan's full body was entombed in the column shaft.

Mortartium records Trajan's Column as an open-test artifact for the Column-Tomb archetype: a vertical monument where the base, inscription, ash tradition, and imperial memory program may carry the funerary layer.

## Source status

This card currently relies on an orienting source card. It requires stronger scholarly or site-authority sources before being promoted beyond stub status.
